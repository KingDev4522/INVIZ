# Quick-Start Card (English + Hindi)

## Shortcuts (remappable at chrome://extensions → Keyboard Shortcuts)

| Action | Windows / Linux | macOS |
|---|---|---|
| VoiceLens on/off | Ctrl+Shift+Y | Command+Shift+Y |
| Start one voice turn | Ctrl+Shift+V | Command+Shift+V |
| Stop speech + cancel task | Ctrl+Shift+X | Command+Shift+X |
| Repeat last announcement | Alt+Shift+R | Alt+Shift+R |

## Earcons (local beeps, no network)

- High blip (660Hz): listening — speak now.
- Mid blip (440Hz): captured — processing.
- Low buzz (220Hz): something failed — listen to the message.

## Everyday use

1. Press the VoiceLens shortcut on any supported page.
2. Tab through the page — every control is announced with its name and state.
3. Press the voice shortcut and speak a request ("What is this page about?",
   "Where is the login button?", "Fill out this application.").
4. Answer the system's questions out loud when it asks for missing information.
5. Say "stop" (or press the stop shortcut) any time to halt everything. You are
   always in charge — your manual Tab/click/type pauses the agent instantly.

## If the system says it can't access a page

Some pages (browser settings, the web store, PDFs, file pages) are closed to all
extensions by Chrome itself. The extension says so honestly instead of guessing.
Switch to a normal website and continue.

## त्वरित शुरुआत (हिंदी)

- VoiceLens चालू/बंद: Ctrl+Shift+Y · एक बार बोलें: Ctrl+Shift+V ·
  रोकें: Ctrl+Shift+X · दोहराएँ: Alt+Shift+R
- बीप: ऊँची = सुन रहा है, बोलें · मध्यम = रिकॉर्ड हो गया · नीची = त्रुटि
- Tab से पेज पर चलें — हर बटन/फ़ील्ड का नाम और स्थिति सुनाई देगी।
- आवाज़ में पूछें ("यह पेज किस बारे में है?", "आवेदन भर दो।"), और जब
  सिस्टम जानकारी माँगे तो जवाब बोलकर दें।
- कभी भी "रुको" कहें या रोकने वाला शॉर्टकट दबाएँ — सब कुछ तुरंत रुक जाएगा।
  आपका हाथ हमेशा ऊपर है: आपका Tab/क्लिक एजेंट को तुरंत रोक देता है।
- अगर सिस्टम कहे कि वह इस पेज तक नहीं पहुँच सकता, तो यह Chrome की पाबंदी है —
  किसी सामान्य वेबसाइट पर जाकर आगे बढ़ें।
