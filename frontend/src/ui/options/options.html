INVIZ · Setup

Options & backend connection

This extension holds no provider keys. All AI traffic goes through your INVIZ backend, which holds the keys server-side. Only the backend address (and an optional access token, if your backend requires one) are stored here, on this machine.

01

INVIZ backend

Validation checks the backend is reachable, then runs its own provider smoke checks (Groq models + Gemini synthesis) and reports each result.

02

Microphone

The test opens your mic for 3 seconds and reports the loudest level it heard. Speak while it listens: a level above ~2% means the mic works and voice capture should too.

03

Voice diagnostics

Runs each voice layer in order and reports PASS/FAIL in plain words: offscreen capture, backend reachability, this page's mic, and a live transcription of a short clip. Speak during steps 1 and 3.
